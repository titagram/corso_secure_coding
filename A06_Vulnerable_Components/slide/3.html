🔎 Esercizio 1: Identificare jQuery 1.7.2

CVE-2011-4969 – Una vulnerabilità XSS nota da anni
🎯 L'Obiettivo dell'Attaccante
jQuery 1.7.2 contiene una vulnerabilità XSS (CVE-2011-4969) che permette l'esecuzione di JavaScript quando si usa .html() o .append() con input non sanitizzato.

La vulnerabilità ha 13+ anni ma è ancora presente in migliaia di applicazioni!
🤔 Il Pattern Vulnerabile
Codice JavaScript che usa jQuery in modo insicuro:
// ❌ VULNERABILE $('#content').html(userInput); $('#content').append(userInput); $(userInput).appendTo('#content'); // Se userInput contiene: // <img src=x onerror="alert(1)"> // → JavaScript viene eseguito!
📝 Come Identificare la Versione
Metodo 1 – DevTools:
Apri F12 → Network o Sources → Cerca jquery nei file caricati

Metodo 2 – Console:
// Nella console del browser (F12 → Console) jQuery.fn.jquery // Output: "1.7.2" $.fn.jquery // Output: "1.7.2"

Metodo 3 – info.php:
http://localhost:8006/info.php # Mostra tutte le versioni dei componenti
