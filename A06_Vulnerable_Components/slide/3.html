🔍 Fase 1: Ricognizione

Scoprire cosa c'è nel buio – L'arte dell'enumerazione
🧠 Il Ragionamento dell'Attaccante
"Prima di attaccare, devo capire cosa ho davanti. Quali porte sono aperte? Quali servizi girano? Che versioni usano?"

Nmap è lo strumento principe per la ricognizione di rete. Ci permette di mappare la superficie d'attacco.
1️⃣ Scan Completo
nmap -sV -p- <TARGET_IP>
-sV: Rileva versioni dei servizi
-p-: Scansiona TUTTE le 65535 porte

Obiettivo: trovare porte non standard come 8002 e 3302
2️⃣ Scan Web Dettagliato
nmap -sV -sC -p 8002 <TARGET_IP>
-sC: Esegue script NSE di default
-p 8002: Focus sulla porta web

Scopriamo: Apache/Nginx? PHP? Headers di sicurezza?
3️⃣ Scan MySQL
nmap -sV -p 3302 \ --script mysql-info,mysql-users \ <TARGET_IP>
mysql-info: Versione e capacità
mysql-users: Enumera utenti

⚠️ MySQL esposto = jackpot per l'attaccante!
💡 Cosa Impariamo
Vulnerabilità identificata: Il database MySQL è esposto direttamente su internet (porta 3302). Questo non dovrebbe MAI accadere in produzione. Un firewall dovrebbe bloccare l'accesso esterno al DB.

Best Practice: Il database dovrebbe essere accessibile SOLO dall'applicazione web, mai direttamente dall'esterno.
