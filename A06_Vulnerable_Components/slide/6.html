⏰ Esercizio 4: PHP 7.4 e MySQL 5.7 EOL

End of Life = Nessun aggiornamento di sicurezza
🐘 PHP 7.4 – EOL: 28 Nov 2022
CVE note non patchate:

• CVE-2021-21703 (PHP < 7.4.27)
• CVE-2022-31630 (PHP < 7.4.32)
• CVE-2023-0662 (PHP < 7.4.33)

Come identificare:
curl -I http://localhost:8006 # Header: X-Powered-By: PHP/7.4.x # Oppure http://localhost:8006/info.php
🗄️ MySQL 5.7 – Non Supportato
CVE note non patchate:

• CVE-2021-3713 (< 5.7.36)
• CVE-2022-21351 (< 5.7.37)

Come identificare:
# Via info.php http://localhost:8006/info.php # Oppure connessione diretta mysql -h localhost -P 3306 -u root \ -prootpassword -e "SELECT VERSION();"
