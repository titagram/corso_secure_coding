🔧 Strumenti di Fingerprinting

Identificare automaticamente i componenti e le loro versioni
🌐 WhatWeb
Identifica tecnologie web usate dal target:
whatweb http://localhost:8006

Output tipico:
http://localhost:8006 [200 OK] Apache, Bootstrap, Country[RESERVED], HTML5, HTTPServer[Debian Linux] [Apache/2.4.54], IP[127.0.0.1], JQuery[1.7.2], PHP[7.4.33], Script, Title[Blog System]
🗺️ Nmap NSE
Script Nmap per identificare versioni:
# Header del server nmap -sV -p 8006 --script \ http-server-header localhost # Informazioni PHP nmap -sV -p 8006 --script \ http-php-version localhost # Scan completo nmap -sV -p 8006 --script "http-*" localhost
🔍 Browser DevTools
Network Tab: Controlla i file JavaScript/CSS caricati per identificare librerie e versioni

Console: Esegui jQuery.fn.jquery per vedere la versione jQuery

Response Headers: Cerca X-Powered-By, Server
# Esempio header di risposta HTTP/1.1 200 OK Server: Apache/2.4.54 (Debian) X-Powered-By: PHP/7.4.33 Content-Type: text/html; charset=UTF-8
💡 Workflow dell'Attaccante
1. WhatWeb per panoramica iniziale → 2. DevTools per dettagli frontend → 3. Nmap per conferma versioni → 4. Ricerca CVE per ogni componente
