📊 Strumenti di Dependency Check

Automatizzare la ricerca di componenti vulnerabili
🔍 OWASP Dependency-Check
Analizza le dipendenze del progetto e cerca CVE:
# Installazione brew install dependency-check # Mac apt install dependency-check # Linux # Scansione dependency-check --scan /path/to/project \ --format HTML --out report.html

Genera report HTML con tutte le CVE trovate, severity e link ai fix.
📦 npm audit / composer audit
Per progetti JavaScript e PHP:
# JavaScript (npm) npm audit npm audit fix # PHP (Composer) composer audit # Python (pip) pip-audit

Integra nella CI/CD per bloccare deploy con vulnerabilità note.
🔔 Snyk
Servizio SaaS per monitoraggio continuo:
# CLI snyk test snyk monitor # Integrazione GitHub # Crea PR automatiche per fix

Free tier disponibile per progetti open source.
🤖 GitHub Dependabot
Aggiornamenti automatici delle dipendenze:

• Scan automatico del repository
• Crea Pull Request per aggiornamenti
• Alerting per nuove CVE
• Gratuito per tutti i repo GitHub
💡 Best Practice
1. Esegui dependency check in CI/CD (blocca build se CVE critiche)
2. Abilita Dependabot/Snyk per alerting continuo
3. Mantieni un inventario aggiornato delle dipendenze (SBOM)
