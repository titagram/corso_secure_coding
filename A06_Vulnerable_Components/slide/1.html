📦 OWASP A06:2021 – Vulnerable & Outdated Components

Quando le dipendenze diventano il tuo peggior nemico
⚠️ La Minaccia
I Vulnerable Components sono al sesto posto nella OWASP Top 10. Ogni libreria, framework o runtime obsoleto porta con sé CVE note che gli attaccanti conoscono e possono sfruttare automaticamente.

Conseguenze: XSS, RCE, data breach, compromissione completa del sistema.
🎯 Il Nostro Obiettivo
Attaccheremo un sistema blog con componenti obsoleti:

• jQuery 1.7.2 (CVE-2011-4969 - XSS)
• PHP 7.4 (End of Life)
• MySQL 5.7 (non supportato)
• Bootstrap 3.4.1 (obsoleto)
🧠 La Mentalità dell'Attaccante
Un attaccante non deve essere un genio: deve solo identificare le versioni dei componenti e cercare exploit già pronti su Exploit-DB, GitHub, Metasploit. Il lavoro sporco l'hanno già fatto altri. jQuery 1.7.2? CVE-2011-4969, XSS garantito. "Dammi le versioni e ti do l'exploit."
