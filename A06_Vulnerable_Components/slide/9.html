🛡️ Mitigazioni

Come proteggere l'applicazione dai componenti vulnerabili
📦 Aggiornare jQuery
<!-- ❌ VECCHIO --> <script src="jquery-1.7.2.min.js"> </script> <!-- ✅ NUOVO --> <script src="https://code.jquery.com /jquery-3.7.1.min.js"></script>

Usa sempre l'ultima versione stabile.
🐘 Aggiornare PHP
# Dockerfile # ❌ VECCHIO FROM php:7.4-apache # ✅ NUOVO FROM php:8.2-apache

PHP 8.2+ è attivamente supportato.
🗄️ Aggiornare MySQL
# docker-compose.yml # ❌ VECCHIO image: mysql:5.7 # ✅ NUOVO image: mysql:8.0

MySQL 8.0+ ha supporto attivo.
✍️ Sanitizzare Input con jQuery
Anche con jQuery aggiornato, sanitizza sempre:
// ❌ VULNERABILE $('#content').html(userInput); // ✅ SICURO: Usa .text() $('#content').text(userInput); // ✅ SICURO: Sanitizza prima var safe = $('<div>').text(userInput).html(); $('#content').html(safe);
🔒 Nascondere Versioni
Non esporre informazioni sulle versioni:
# php.ini expose_php = Off # httpd.conf ServerTokens Prod ServerSignature Off Header unset X-Powered-By # Rimuovi info.php in produzione! rm /var/www/html/info.php
