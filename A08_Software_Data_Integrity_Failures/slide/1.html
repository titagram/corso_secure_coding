🔐 OWASP A08:2021 – Software & Data Integrity Failures

Quando i dati serializzati diventano armi e gli aggiornamenti tradiscono
⚠️ La Minaccia
I Software & Data Integrity Failures sono all'ottavo posto nella OWASP Top 10. Includono: deserializzazione non sicura, mancanza di verifica di integrità, aggiornamenti da sorgenti non verificate.

Conseguenze: RCE (Remote Code Execution), supply chain attacks, compromissione totale del sistema.
🎯 Il Nostro Obiettivo
Attaccheremo un sistema di gestione plugin vulnerabile:

1. Deserializzazione → RCE
2. Hash non verificati → Modifica plugin
3. Upload non controllato → Web shell
4. Aggiornamenti insicuri → Supply chain
🧠 La Mentalità dell'Attaccante
Un attaccante cerca punti dove l'applicazione deserializza dati che può controllare. Se trova una classe con __wakeup() o __destruct() che esegue operazioni pericolose, può creare un oggetto serializzato malevolo che eseguirà codice arbitrario quando viene deserializzato. È come consegnare un pacco bomba che esplode quando viene aperto.
