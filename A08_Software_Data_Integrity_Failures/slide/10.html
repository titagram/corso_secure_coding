Cosa abbiamo imparato e come applicarlo
📚 Cosa Abbiamo Esplorato
1. Deserializzazione: Da unserialize() a RCE con magic methods

2. Payload: Web shell, reverse shell, lettura file

3. Integrità: Hash generati ma mai verificati

4. Upload: Nessun controllo, path traversal

5. Supply Chain: Aggiornamenti non verificati, MITM
🧠 La Lezione Chiave
Mai fidarsi di dati esterni.

La deserializzazione è come aprire un pacco di uno sconosciuto: potrebbe contenere una bomba. L'integrità va sempre verificata, non basta generare un hash se poi non lo controlli.

"Se non verifichi, non proteggi."

Supply chain attacks colpiscono migliaia di sistemi in un colpo solo!
✅ Checklist di Sicurezza
☐ Evitare unserialize() su dati utente – usare JSON
☐ Se necessario, usare whitelist di classi consentite
☐ Verificare hash SHA-256 prima di installare/eseguire
☐ Implementare firma digitale per pacchetti/plugin
☐ Validare upload: tipo, dimensione, nome, contenuto
☐ Usare solo HTTPS per aggiornamenti
☐ Verificare certificati SSL
