📬 Lab Parte 3: Estrarre gli Header Email

Come accedere alle informazioni nascoste di un'email
📧 Gmail
Passaggi:

1. Apri l'email sospetta

2. Clicca sui tre puntini (⋮) in alto a destra

3. Seleziona "Mostra originale"

4. Si aprirà una nuova finestra con:
• Header completi • Risultati SPF/DKIM/DMARC • Sorgente raw del messaggio
📮 Outlook / Microsoft 365
Outlook Desktop:
Apri email → File → Proprietà → "Intestazioni Internet"

Outlook Web (OWA):
Apri email → ⋮ → "Visualizza dettagli messaggio" o "View message source"

Nuovo Outlook:
⋮ → Visualizza → Visualizza origine messaggio
🔧 Strumenti di Analisi
Una volta copiati gli header, incollali in:

MXToolbox Header Analyzer:
https://mxtoolbox.com/EmailHeaders.aspx

Google Admin Toolbox:
https://toolbox.googleapps.com/apps/messageheader/

Mail Header Analyzer:
https://mailheader.org
💡 Consiglio
Chiedi sempre al cliente di inviarti la mail sospetta come allegato .eml (non inoltrata!) per preservare gli header originali.
