🧠 La Lezione Chiave
SSRF trasforma il server in un proxy fidato.

Il server può raggiungere risorse che tu non puoi vedere: localhost, rete interna, metadata services. Se il server fetcha URL senza validazione, hai accesso a tutta l'infrastruttura.

"Mai fidarsi di URL forniti dall'utente."

Il breach Capital One 2019 (100M record) è partito da SSRF!
✅ Checklist di Sicurezza
☐ Implementare whitelist di domini consentiti
☐ Bloccare IP privati e localhost (tutte le forme)
☐ Bloccare 169.254.169.254 (metadata services)
☐ Permettere solo HTTP/HTTPS
☐ Disabilitare o validare redirect
☐ Risolvere DNS e validare IP risultante
☐ Implementare timeout brevi
