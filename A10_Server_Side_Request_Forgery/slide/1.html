🌐 OWASP A10:2021 – Server-Side Request Forgery

Quando il server diventa il tuo proxy personale verso risorse interne
⚠️ La Minaccia
SSRF è al decimo posto nella OWASP Top 10. Un attaccante può indurre il server a fare richieste verso destinazioni arbitrarie: risorse interne, metadata cloud, servizi protetti.

Conseguenze: Accesso a dati interni, furto credenziali AWS/GCP, port scanning, bypass firewall.
🎯 Il Nostro Obiettivo
Attaccheremo un sistema di URL Preview vulnerabile:

1. Accesso a localhost
2. Metadata services (AWS/GCP/Azure)
3. Port scanning interno
4. Bypass filtri
5. Protocolli pericolosi (file://, gopher://)
🧠 La Mentalità dell'Attaccante
SSRF trasforma il server in un proxy fidato. Il server ha accesso a risorse che tu non puoi raggiungere: rete interna, localhost, metadata services. L'attaccante si chiede: "Cosa può vedere il server che io non posso vedere?". Se il server fetcha URL senza validazione, può essere usato per esplorare l'intera infrastruttura.
