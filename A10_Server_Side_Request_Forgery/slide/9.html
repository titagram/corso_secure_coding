🛡️ Mitigazioni

Come proteggere l'applicazione da SSRF
✅ Whitelist Domini
// ✅ CORRETTO: Solo domini specifici $allowed = ['example.com', 'api.trusted.com']; $parsed = parse_url($url); $host = $parsed['host']; if (!in_array($host, $allowed)) { die("Domain not allowed"); }

Whitelist > Blacklist
🚫 Blocca IP Privati
// ✅ CORRETTO: Blocca IP privati function isPrivateIP($ip) { return !filter_var($ip, FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE); } $ip = gethostbyname($host); if (isPrivateIP($ip)) { die("Private IP blocked"); }
📡 Solo HTTP/HTTPS
// ✅ CORRETTO: Limita protocolli $scheme = parse_url($url, PHP_URL_SCHEME); if (!in_array($scheme, ['http', 'https'])) { die("Only HTTP/HTTPS"); } // cURL: limita protocolli curl_setopt($ch, CURLOPT_PROTOCOLS, CURLPROTO_HTTP | CURLPROTO_HTTPS); curl_setopt($ch, CURLOPT_REDIR_PROTOCOLS, CURLPROTO_HTTP | CURLPROTO_HTTPS);
🔄 Gestione Redirect
// ✅ CORRETTO: Disabilita redirect curl_setopt($ch, CURLOPT_FOLLOWLOCATION, false); // Oppure: valida ogni redirect curl_setopt($ch, CURLOPT_MAXREDIRS, 3); // + callback per validare ogni URL

I redirect possono bypassare i filtri!
⏱️ Timeout e Limiti
curl_setopt($ch, CURLOPT_TIMEOUT, 2); // Max 2 secondi curl_setopt($ch, CURLOPT_CONNECTTIMEOUT, 1); // Max 1 secondo connessione curl_setopt($ch, CURLOPT_MAXFILESIZE, 1048576); // Max 1MB risposta
