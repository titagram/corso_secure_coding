🔬 Fase 4: Estrazione degli Hash

Trovare gli aghi nel pagliaio – Parsing automatizzato
🧠 Il Ragionamento dell'Attaccante
"Il dump SQL è enorme. Devo estrarre solo gli hash delle password per crackarli. Ogni algoritmo ha un pattern riconoscibile: MD5 sono 32 caratteri hex, SHA256 sono 64..."

Usiamo grep con regex per estrarre automaticamente ogni tipo di hash.
📜 Lo Script di Estrazione
# MD5 (32 caratteri hex) grep -oE '[a-fA-F0-9]{32}' dump.sql \ > md5_hashes.txt # SHA1 (40 caratteri hex) grep -oE '[a-fA-F0-9]{40}' dump.sql \ > sha1_hashes.txt # SHA256 (64 caratteri hex) grep -oE '[a-fA-F0-9]{64}' dump.sql \ > sha256_hashes.txt # bcrypt (pattern $2a$, $2b$, $2y$) grep -oE '\$2[aby]\$[0-9]{2}\$[A-Za-z0-9./]{53}' \ dump.sql > bcrypt_hashes.txt
