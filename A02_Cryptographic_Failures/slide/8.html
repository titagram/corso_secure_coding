🛡️ Conclusioni e Remediation

Da vulnerabili a sicuri – Le contromisure
❌ Vulnerabilità Trovate
1. Database esposto su internet
MySQL accessibile dalla rete pubblica

2. Password root debole
"rootpassword" crackabile in secondi

3. Hash password con MD5
Algoritmo obsoleto, nessun salt

4. Dati sensibili in chiaro
Carte di credito non cifrate nel DB

5. Nessun rate limiting
Brute-force senza limiti
✓ Remediation
1. Firewall sul database
MySQL solo su localhost/rete interna

2. Password policy rigorosa
Minimo 16 caratteri, complessità alta

3. Usare bcrypt/Argon2
password_hash() in PHP con PASSWORD_BCRYPT

4. Cifratura dati sensibili
AES-256-GCM per carte di credito

5. Fail2ban + rate limiting
Ban dopo 5 tentativi falliti
🔐 Codice Sicuro per Password
// ❌ SBAGLIATO - Mai fare così! $hash = md5($password); // ✓ CORRETTO - Usa bcrypt $hash = password_hash( $password, PASSWORD_BCRYPT, ['cost' => 12] ); // Verifica if (password_verify($input, $hash)) { // Login OK }
