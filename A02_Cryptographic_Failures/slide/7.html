⚔️ Fase 5: Cracking degli Hash

Trasformare gli hash in password in chiaro
🧠 Il Ragionamento dell'Attaccante
"Ho gli hash ma non so quale algoritmo è stato usato. Prima identifico il tipo, poi uso Hashcat con la modalità corretta. MD5 è velocissimo da crackare, bcrypt molto più lento..."
🔍 Identificazione con hash-identifier
$ hash-identifier ╔═══════════════════════════════╗ ║ HASH IDENTIFIER ║ ╚═══════════════════════════════╝ HASH: 5f4dcc3b5aa765d61d8327deb882cf99 Possible Hashs: [+] MD5 [+] Domain Cached Credentials
Tip: L'identificatore non è sempre preciso al 100%. La lunghezza e il pattern aiutano a confermare.
📊 Hashcat Modes
Ogni algoritmo ha un codice (mode) in Hashcat:
MD5 → mode 0 ⚡ Velocissimo SHA1 → mode 100 ⚡ Veloce SHA256 → mode 1400 ⚡ Veloce bcrypt → mode 3200 🐢 Molto lento
Nota: bcrypt è lento BY DESIGN per resistere al cracking!
💥 Attacco con Hashcat
# Cracking MD5 con wordlist hashcat -m 0 -a 0 md5_hashes.txt rockyou.txt # Risultato: 5f4dcc3b5aa765d61d8327deb882cf99:password 482c811da5d5b4bc6d497ffa98491e38:password123 098f6bcd4621d373cade4e832627b4f6:test Session..........: hashcat Status...........: Cracked Hash.Mode........: 0 (MD5) Speed.#1.........: 15.2 GH/s ← 15 MILIARDI di tentativi/sec!
⚠️ Lezione chiave: MD5/SHA1/SHA256 senza salt sono inutili per le password. Con GPU moderne, miliardi di tentativi al secondo rendono il cracking banale.
