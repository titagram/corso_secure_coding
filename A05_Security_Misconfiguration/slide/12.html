📚 Cosa Abbiamo Esplorato
1. Config Files: config.php, environment.txt esposti

2. Directory Listing: /uploads/, /backups/, /logs/

3. Admin Panel: Accesso senza autenticazione

4. Backup Files: Dump SQL scaricabili

5. Debug Mode: Stack trace e path disclosure

6. Server Signature: Fingerprinting facilitato
🧠 La Lezione Chiave
Security Misconfiguration è spesso la vulnerabilità più semplice da sfruttare e più semplice da prevenire.

Il problema: nessuno controlla le configurazioni di default.

"Il 90% delle misconfigurazioni si previene con una checklist e 10 minuti di hardening."

Strumenti come Nikto e Gobuster trovano in secondi quello che un attaccante troverebbe in minuti.
✅ Checklist di Sicurezza
☐ File di configurazione fuori dalla document root
☐ Directory listing disabilitato (Options -Indexes)
☐ Backup e log non accessibili via web
☐ Debug mode disabilitato in produzione
☐ Server signature nascosta (ServerTokens Prod)
☐ Security headers configurati
☐ Pannelli admin protetti con autenticazione
☐ Nessuna credenziale hardcoded nel codice
☐ Scansione periodica con Nikto/Nmap
