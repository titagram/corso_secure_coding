🔧 Strumenti di Automazione (Parte 2)

Gobuster e Nmap NSE – Directory Bruteforce e Script Scanning
📂 Gobuster
Scopo: Brute-force di directory e file nascosti
gobuster dir \ -u http://localhost:8005 \ -w /usr/share/wordlists/dirb/common.txt \ -x php,txt,sql,bak,log

Flag utili:
• -x estensioni da cercare
• -t 50 thread paralleli
• -o results.txt output su file
🗺️ Nmap NSE
Scopo: Script specializzati per enumeration HTTP
# Enumeration generale nmap -p 8005 --script http-enum localhost # Headers e server info nmap -p 8005 --script http-headers localhost # Cerca backup e config nmap -p 8005 --script http-config-backup localhost
🎯 Workflow Completo dell'Attaccante
# 1. Fingerprinting whatweb http://localhost:8005 # 2. Vulnerability scan nikto -h http://localhost:8005 -o nikto_results.txt # 3. Directory bruteforce gobuster dir -u http://localhost:8005 \ -w /usr/share/wordlists/dirb/common.txt \ -x php,txt,sql,bak,log -o gobuster_results.txt # 4. Nmap enumeration nmap -p 8005 --script http-enum,http-config-backup localhost # 5. Sfruttamento manuale nel browser
📦 Installazione (Kali Linux)
sudo apt update && sudo apt install whatweb nikto gobuster nmap
