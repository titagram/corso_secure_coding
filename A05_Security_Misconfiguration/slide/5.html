🔓 Esercizio 3: Pannello Admin Senza Autenticazione

Quando dimenticano di proteggere le pagine sensibili
🎯 L'Obiettivo dell'Attaccante
Molte applicazioni hanno pannelli di amministrazione che dovrebbero essere protetti. Ma cosa succede se lo sviluppatore dimentica di aggiungere i controlli?

Cosa possiamo ottenere?
• Lista completa degli utenti
• Email e dati personali
• Documenti privati
• Statistiche del sistema
🤔 La Vulnerabilità
Nel file admin/panel.php:
// ❌ VULNERABILE // Nessun controllo di sessione! // Nessun controllo sul ruolo! $users = $conn->query( "SELECT * FROM users" ); $documents = $conn->query( "SELECT * FROM documents" );
📝 L'Attacco
Step 1: Accedi direttamente al pannello admin senza login:
http://localhost:8005/admin/panel.php

Step 2: Osserva tutti i dati esposti:

• Utenti: ID, username, email, nome completo, ruolo
• Documenti: Tutti i file caricati, inclusi quelli privati
• Metadati: Date di creazione, proprietari, dimensioni
🛡️ Lezione per il Difensore
1. Sempre verificare $_SESSION['user_id'] e $_SESSION['role']
2. Implementare middleware di autenticazione
3. Opzionale: restrizione IP per il pannello admin
