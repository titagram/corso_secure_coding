🛡️ Mitigazioni

Come correggere le misconfigurazioni di sicurezza
📄 File Sensibili
# Sposta fuori document root /var/www/config/ ← config /var/www/html/ ← document root # Blocca in Apache <FilesMatch "\.(env|ini|bak|sql)$"> Require all denied </FilesMatch>
📁 Directory Listing
# httpd.conf Options -Indexes +FollowSymLinks # Oppure index.php vuoto <?php http_response_code(403); die('Access Denied'); ?>
🔓 Autenticazione
# admin/panel.php session_start(); if (!isset($_SESSION['user_id'])) { header('Location: /login.php'); exit; } if ($_SESSION['role'] !== 'admin') { die('Access Denied'); }
🐛 Debug Mode
# php.ini (produzione) display_errors = Off display_startup_errors = Off log_errors = On error_log = /var/log/php/errors.log # config.php define('DEBUG_MODE', false);
🏷️ Server Signature e Headers
# httpd.conf ServerTokens Prod ServerSignature Off # Security Headers Header always set X-Frame-Options "DENY" Header always set X-Content-Type-Options "nosniff" Header always set X-XSS-Protection "1; mode=block"
