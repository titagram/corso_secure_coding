⚙️ OWASP A05:2021 – Security Misconfiguration

Quando le configurazioni di default diventano il punto debole
⚠️ La Minaccia
La Security Misconfiguration è al quinto posto nella OWASP Top 10. È una delle vulnerabilità più comuni: server configurati male, file sensibili esposti, debug mode attivo in produzione, directory listing abilitato.

Conseguenze: accesso a credenziali, dump del database, informazioni sensibili esposte, takeover completo del sistema.
🎯 Il Nostro Obiettivo
Attaccheremo un sistema di gestione documentale mal configurato. Esploreremo ogni falla di configurazione:

1. Config Files → 2. Directory Listing → 3. Admin Panel → 4. Backup/Logs → 5. Debug Info
🧠 La Mentalità dell'Attaccante
Un attaccante non cerca solo bug nel codice: cerca configurazioni lasciate di default, file dimenticati, directory esposte. Si chiede: "Cosa hanno lasciato accessibile per errore?", "Quali file di backup posso trovare?". In questo laboratorio useremo tecniche di enumeration e strumenti come Nikto, Gobuster e Nmap.
