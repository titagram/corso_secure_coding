📋 Esercizio 5: Log Files e Debug Mode

Informazioni preziose nascoste nei log e negli errori
📄 Log Files Esposti
I file di log possono contenere:

• Query SQL con parametri sensibili
• Stack trace completi
• Path del filesystem
• IP e sessioni degli utenti
• Errori che rivelano la logica interna
http://localhost:8005/logs/app.log
🐛 Debug Mode Attivo
Configurazione vulnerabile in config.php:
// ❌ VULNERABILE define('DEBUG_MODE', true); ini_set('display_errors', 1); error_reporting(E_ALL);

Ogni errore PHP mostra:
• Path completi dei file
• Nomi di funzioni e classi
• Parametri passati
📝 L'Attacco
Step 1: Accedi ai log:
http://localhost:8005/logs/app.log

Step 2: Genera un errore per vedere il debug output. Inserisci caratteri speciali in un form o accedi a una pagina inesistente.

Step 3: Analizza lo stack trace esposto:
Fatal error: Uncaught PDOException: SQLSTATE[42000] in /var/www/html/db_connect.php on line 15 Stack trace: #0 /var/www/html/login_process.php(23): PDO->query() #1 {main}
🛡️ Lezione per il Difensore
1. display_errors = Off in produzione
2. Logga gli errori su file, non mostrarli: log_errors = On
3. Sposta i log fuori dalla document root
