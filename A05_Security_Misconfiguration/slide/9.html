🔧 Strumenti di Automazione (Parte 1)

WhatWeb e Nikto – Fingerprinting e Vulnerability Scanning
🌐 WhatWeb
Scopo: Identificare tecnologie utilizzate dal sito
whatweb http://localhost:8005

Cosa trova:
• Versione di Apache e PHP
• Framework utilizzati
• CMS (WordPress, Joomla, etc.)
• Cookies e headers
• Moduli del server
🔍 Nikto
Scopo: Scanner web che cerca migliaia di vulnerabilità note
nikto -h http://localhost:8005

Cosa trova:
• Directory listing abilitato
• File di backup esposti
• Configurazioni errate
• Headers mancanti
• Server signature esposta
📊 Output Tipico di Nikto
+ Server: Apache/2.4.54 (Debian) + The X-XSS-Protection header is not defined + The X-Content-Type-Options header is not set + Directory indexing found: /uploads/ + Directory indexing found: /backups/ + OSVDB-3092: /config.php: Configuration file found + OSVDB-3092: /backup.sql: Database backup found + /admin/: Admin panel found without authentication
