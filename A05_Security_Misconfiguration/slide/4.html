📁 Esercizio 2: Directory Listing Abilitato

Quando Apache ti mostra tutto il contenuto delle cartelle
🎯 L'Obiettivo dell'Attaccante
Se una directory non ha un file index.php o index.html, e il Directory Listing è abilitato, Apache mostra l'elenco completo dei file.

Cosa possiamo trovare?
• File di backup dimenticati
• Log con informazioni sensibili
• Upload degli utenti
• File di configurazione
🤔 La Configurazione Vulnerabile
Nel file httpd.conf:
# ❌ VULNERABILE Options Indexes FollowSymLinks # Indexes = mostra il contenuto # delle directory senza index file

Dovrebbe essere:
# ✅ CORRETTO Options -Indexes +FollowSymLinks
📝 L'Attacco
Naviga direttamente alle directory sensibili e osserva l'elenco completo dei file:
http://localhost:8005/uploads/ → File caricati dagli utenti http://localhost:8005/backups/ → Dump SQL del database! http://localhost:8005/logs/ → Log applicativi con info sensibili http://localhost:8005/admin/ → Pannello admin e file nascosti

Risultato: Puoi vedere e scaricare ogni singolo file in queste directory!
🛡️ Lezione per il Difensore
1. Options -Indexes nella configurazione Apache
2. Aggiungi un index.php vuoto che ritorna 403 Forbidden
3. Sposta directory sensibili fuori dalla document root
